# 本地音乐以 MediaStore 系统媒体库为来源，音频权限 + 文件夹黑名单取代目录授权与内容指纹

> 推翻 [ADR 0019](0019-local-music-via-saf-folder.md)（SAF 目录扫描）与 [ADR 0021](0021-local-song-identity-content-fingerprint.md)（内容指纹身份）；[ADR 0020](0020-local-metadata-override-layer.md) 的元数据覆盖层继续有效，仅存储键随身份调整。

上一版本地音乐用 SAF 目录授权加自研遍历：用户逐个授权文件夹，App 递归扫目录、逐文件算内容指纹、逐文件开解析器读标签，几千首歌的首扫要等几分钟；某些系统 provider 不给文件大小或修改时间时，「路径 + 大小 + 修改时间」的增量失效退化成全量重读；选错目录、目录重叠被拒、授权被系统回收，任何一个都会让页面空掉或整页灰掉。决定：扫描来源改为 Android 系统媒体库（MediaStore）——持有一次标准音频读取权限即查询 `MediaStore.Audio.Media`（`IS_MUSIC != 0`，Android 10+ 附加 `IS_PENDING = 0`、Android 11+ 附加 `IS_TRASHED = 0`），毫秒级出全库；标题、艺术家、专辑、时长、音轨号、年份、专辑封面全部是系统预抽取的现成结果，`.nomedia`、隐藏文件与铃声、闹钟、通知、录音、播客由系统媒体扫描器天然过滤——删除格式白名单等 App 侧判断，扫描不再有进度与取消，它只是一次查询。文件夹范围从「授权文件夹」改为「全机音乐 + 排除文件夹黑名单」（对齐同类播放器椒盐的方式）：排除清单是一组文件夹路径，匹配「该文件夹及其全部子文件夹」，从库行路径派生候选、开关即时生效、不需要重扫，状态随库快照落盘。歌曲身份从内容指纹改为媒体库行 ID（Android 10+ 带卷名限定防跨卷撞号），播放的 `local:` 命名空间与 `content://` 直读不变。理由有三：**首扫成本**——每文件一次指纹 IO + 一次标签解析降为一次数据库查询，扫描在本地音乐链路中的存在感归零；**增量失效**——媒体库增量由系统维护，自研增量的「provider 缺大小/修改时间即退化全量」问题不再存在；**授权摩擦**——逐文件夹 SAF 授权（选择器、重叠被拒、授权被回收即整页空掉）换为一次标准音频权限，拒绝与撤销都有明确的引导与灰显路径。

## Considered Options

- **SAF 目录授权 + 自研扫描（否决）**：权限范围最小，但首扫 I/O 与目录规模成正比（逐文件指纹 + 标签解析）、增量失效依赖 provider 给全「大小 + 修改时间」（缺一个就退化全量重读）、逐文件夹授权摩擦大且授权被回收即整页空掉。
- **MediaStore + 指定文件夹白名单（否决）**：读媒体库但仍按目录过滤——过滤条件散在查询里，用户仍要理解「该选哪些文件夹」；黑名单（默认全收、只排除不要的）零配置开听。
- **MediaStore 系统媒体库 + 排除文件夹黑名单（采纳）**：一次音频权限、查询即事实；身份用媒体库行 ID，覆盖层键随之调整。

## Consequences

- 首次进入是「授权 → 秒级全库」：没有首扫等待、没有进度条与取消。进入页面与授权成功后各静默刷新一次（整库重查 → 按身份 diff → 合并覆盖层 → 提交），顶栏「重新扫描」走同一管线并提示「新增 x、移除 y」。
- 权限模型：Android 13+ 申请 `READ_MEDIA_AUDIO`，12 及以下申请 `READ_EXTERNAL_STORAGE`（清单标 `maxSdkVersion 32`）；拒绝 → 解释空态 + 「重试 / 去系统设置」；撤销 → 快照灰显 + 重新授权横幅，不放空列表假装没歌，重新授权自动刷新；进页面与回前台（`ON_RESUME`）都复查权限。
- 歌曲身份 = 行 ID：同卷内移动 / 改名文件行 ID 不变，覆盖层编辑仍然保住；文件被删除后重新加入则媒体库给出新行 ID，按行 ID 记键的覆盖层编辑随之丢失——已知取舍（覆盖层数据量小、重编辑成本低）。同一内容的多个副本各自成行显示，App 不做内容级去重。
- 外置 USB OTG 上媒体库不索引的音频扫不到——系统边界，与同类播放器一致，不做 SAF 补充。
- ADR 0020 覆盖层继续有效：仍是独立文件、原子写、只存非空值，键从指纹换成「卷名:行 ID」。
- 升级迁移：旧索引 v1 与旧覆盖层 v1 都按内容指纹记身份，与新身份对不上，首次读取即整份丢弃（删除文件、不迁移不报错）；旧 SAF 目录授权残留不清理也不使用。
- 封面：按专辑成员行的 `ALBUM_ID` 取系统预抽取的专辑图（albumart content URI），图片加载器直接加载与缓存；文件夹封面文件（`cover.jpg` 类）与音频内嵌图不再读取；无图专辑显示占位图。
- 库快照 v2：歌曲行 + 排除清单一起落盘，照旧原子写（临时文件 + rename）；哪些音频算音乐（`IS_MUSIC` 的判定）由系统媒体扫描器维护。
