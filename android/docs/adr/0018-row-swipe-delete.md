# 歌曲行左滑露出操作按钮：行内操作不再占常驻图标位

歌曲列表行原在行尾放一个「更多」图标承载行内操作，但除下载列表外所有列表传的都是空实现，点它没有任何反应，是死入口；本次行样式改版又把封面移到行尾，图标位与封面争抢同一处。故行内操作改为手势承载：手指从右向左拖动某行（内容向左侧移出）→ 露出行尾的操作按钮 → 点按钮才执行。启用范围限定在有移除语义的列表：下载列表已完成行露「删除」（删本地文件，保留确认弹窗）、下载中行露「取消」（直接执行，无确认）、本地歌单详情行露「移出歌单」（直接执行，无确认）；专辑歌曲、收藏、最近播放、最新歌曲、歌手上传、搜索歌曲等无移除语义的列表左滑无反应。同一列表同一时刻只允许一行处于展开态（滑开新的一行自动收起旧行），点行内其它区域或上下滚动列表即收起。

## Considered Options

- **行尾常驻图标（现状，已否决）**：除下载列表外全是空实现，是死入口；封面移到行尾后，图标位与封面争抢同一处。
- **长按整行弹操作菜单（否决）**：不占常驻位，但可发现性差，且长按在列表里已被滚动与拖动占用。
- **左滑到底即删除（否决）**：一滑即不可逆，下载还会删本地文件，误触代价高。
- **左滑露出按钮后再点（采纳）**：滑动只露出、不产生副作用，删除多一道手指动作。

## Consequences

- 行内左滑与整行点歌共存：横向拖动越过触摸阈值才进入滑动，纵向滚动不受影响；展开态下点行内容只收起，不触发点歌。
- 行内操作不再有常驻入口：以后新增行内操作一律走同一手势与同一个按钮位，按钮文案即操作名。
- 互斥展开状态由列表页持有，滑动与收起动画只作用于行内容的水平位移，不改变行的测量尺寸。
- 下载中的「取消」复用 deleteDownload：取消的同时删除 `.part` 半文件，该曲下次下载从 0 开始（与既有删除行为一致）。
- 手势方向一律以「内容向哪移动」表述（「内容向左侧移出」），不用左/右滑指代，避免手指向与内容向的歧义（同 ADR 0013 的教训）。
