# Android

面向终端用户的音乐播放客户端上下文。从后端获取内容目录，负责浏览、播放、收藏、下载，并在中国厂商 ROM 的严格后台限制下保持播放不中断。

## Language

### 播放

**播放队列（Queue）**:
当前会话中等待播放的歌曲序列，每次点播时被整体替换。
_Avoid_: 播放列表（这个词保留给后端的管理员策展合集，两者是不同概念）

**播放进度**:
当前歌曲在队列中的位置与播放时间点，定期持久化，用于 App 重启后恢复。

**迷你播放器（Mini Player）**:
常驻于所有页面底部的播放控制条，展示当前歌曲与进度。

**全屏播放器**:
展示封面、进度条与完整控制功能的全屏播放页面。

### 本地数据

**最近播放**:
用户点播过的歌曲 ID 记录（最多 50 条），仅存 ID，展示时回后端换取详情。
_Avoid_: 播放历史

**已下载歌曲**:
用户主动下载、期望离线保留的歌曲快照。与音频缓存不同：下载是用户显式拥有、不自动清除的内容。
_Avoid_: 离线歌曲

**音频缓存**:
播放过程中自动落盘的音频数据，按 LRU 策略自动驱逐，用户不可感知也不可管理。
_Avoid_: 下载（缓存不是下载）

### 后台生存

**保活**:
对抗系统杀进程、维持播放服务存活的一切手段的统称。

**双层前台服务**:
保活的核心结构：播放服务与独立的轻量守护服务同时驻前台，互为备份。

**自启动恢复**:
设备开机后无需用户打开 App 即恢复守护服务的机制。

**白名单引导**:
引导用户手动到厂商系统的自启动/电池设置中放行本 App 的流程——程序无法代为配置，只能跳转。

### 浏览

**热门歌曲（Trending）**:
首页展示的歌曲榜单，按近一个月的播放量聚合排序。
_Avoid_: 排行榜（后端没有榜单实体，只是读取侧的排序视图）

**专辑歌曲页**:
展示某张专辑下全部歌曲的详情页，由首页最新专辑、抽屉专辑列表或分类专辑页的专辑卡片进入（分类下仅一张专辑时由分类专辑页直跳），顶栏标题为专辑名。

**分类专辑页**:
展示某个分类下全部专辑的网格页，由分类列表页进入；分类下仅有一张专辑时不展示此页，直接进入该专辑的歌曲页，返回时回到分类列表页。
_Avoid_: 分类歌曲页（分类已下放专辑而非歌曲，该页面已废弃）
