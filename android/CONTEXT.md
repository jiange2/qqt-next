# Android

面向终端用户的音乐播放客户端上下文。从后端获取内容目录，负责浏览、搜索、播放、收藏、下载，并在中国厂商 ROM 的严格后台限制下保持播放不中断。

## Language

### 播放

**播放队列（Queue）**:
当前会话中等待播放的歌曲序列，每次点播时被整体替换。
_Avoid_: 播放列表（弃用词，易与本地歌单混淆，两者是不同概念）

**队列位置**:
当前歌曲在播放队列中的序号（从 1 计），全屏播放器展示为「第几首 / 共几首」。
_Avoid_: 播放进度（那还包含播放时间点）

**播放模式**:
主控行左端入口控制的队列播完行为，三选一：随机播放、顺序播放、单曲循环；点击图标弹出菜单选择，菜单打开时继续点图标按序轮转；按播放队列的来源分别记忆保持，无记忆的来源回退默认记忆（ADR 0008、ADR 0015）。
_Avoid_: 循环模式（旧名）、重复模式

**来源记忆**:
播放模式按队列来源分别记忆的本机偏好：专辑、本地歌单、收藏、下载列表各记一份，首页等临时列表共享「默认记忆」（兼作新来源的初值）；点播给队列打上来源标记，播放器内切模式只写当前来源的记忆（ADR 0015）。
_Avoid_: 全局播放模式（旧语义：一份设置管所有来源）、每首歌记忆

**随机播放**:
播放模式之一，乱序遍历整个播放队列，一轮播完重新随机再来。
_Avoid_: 随机循环、洗牌

**顺序播放**:
播放模式之一且为默认态：按队列顺序循环整个队列，永不停在队尾——与行业“顺序播完即止”相反（ADR 0008）。
_Avoid_: 列表循环（同指本模式，统一叫顺序播放）、顺序循环

**单曲循环**:
播放模式之一，当前歌曲无限重复。
_Avoid_: 单曲重复

**播放进度**:
当前歌曲在队列中的位置与播放时间点，持久化于队列快照，用于 App 重启后恢复。

**迷你播放器（Mini Player）**:
常驻于除全屏播放器外所有页面底部的播放控制条，与主内容直接相接（无空隙），展示当前歌曲与进度。

**歌曲封面**:
歌曲实体自带的图片，随歌曲在后台上传维护。列表缩略图与播放器展示的歌曲图片都是它。
_Avoid_: 专辑封面（专辑是独立实体、有自己的图片，当前客户端不使用）、歌曲图片、封面图

**全屏播放器**:
展示歌曲封面、进度条与完整控制功能的全屏播放页面，由迷你播放器进入；内含歌曲页与歌词页两个并列页，由顶栏页签或横滑切页手势互切；通过顶栏下箭头或系统返回关闭，关闭后回到进入前页面，播放不中断。
_Avoid_: 播放器页（那是单指歌曲页的叫法，与整页概念冲突）

**功能图标行**:
全屏播放器中标题区下方的一排功能图标：喜欢 / 播放设置 / 下载 / 加入歌单 / 更多。
_Avoid_: 第一排按钮、第二行按钮（旧版文档中本行的旧称；旧“第一行按钮”见主控行）

**播放设置**:
功能图标行第二位图标打开的底部浮层，聚合播放相关的可调项：定时关闭。
_Avoid_: 音效、均衡器（图标位旧称；均衡器功能已移除，图标只承载播放设置入口）

**切歌**:
播放进入下一次「开始播放」的事件：换成另一首歌、重新点选或恢复装载同一首、单曲循环开启新一轮，各算一次切歌；访问事实上报、进度保存与「播完本曲」定时结算随切歌各执行一次。播放中途的歌词行刷新不构成切歌（ADR 0016）。
_Avoid_: 切曲事件（Media3 回调名，本上下文不用）、换歌

**定时关闭**:
播放设置内的会话级倒计时：到点暂停播放，不杀服务、不清队列；「播完本曲」在当前歌曲自然放完时暂停，期间手动切歌或点播新歌即撤销该定时。
_Avoid_: 睡眠定时、定时停止

**主控行**:
全屏播放器底部的播放控制行，包含播放模式、上一首、播放/暂停、下一首与队列入口。
_Avoid_: 底部主控、第一行按钮、第二行按钮

**队列入口**:
主控行第五位图标打开的底部浮层，展示播放队列并支持队列内跳播（点选切歌、不重建队列，浮层保持打开）。
_Avoid_: 播放列表入口（统一叫队列入口，「播放列表」为弃用词）

**中部播放区**:
全屏播放器顶栏与主控行之间的内容区，歌曲页含歌曲封面、标题/歌手/队列位置、功能图标行与进度条，歌词页中歌曲封面的位置由歌词区替代；正常屏固定高度、整体不可拖动，矮屏放不下时才整体滚动托底。
_Avoid_: 主体部分、播放器主体

**更多菜单**:
功能图标行第五位「更多」图标打开的底部浮层，聚合当前歌曲的扩展操作，现仅「评分」一项，按可扩展列表实现。
_Avoid_: 第一排第5个按钮、更多选项

**歌曲页**:
全屏播放器的默认页（页签「歌曲」），展示歌曲封面、标题/歌手/队列位置、功能图标行与进度条。
_Avoid_: 播放器页、主界面

**歌词页**:
全屏播放器中与歌曲页并列的页（页签「歌词」），歌曲封面的位置由歌词区替代，其余区块与歌曲页一致；支持点击歌词行跳转播放进度。

**歌词**:
当前播放歌曲的逐行时间轴歌词文本，歌词页随播放进度高亮当前行。歌曲本无歌词数据时展示「暂无歌词」占位（终态）；有数据但取回失败（网络、下载、解析）时展示「歌词加载失败」占位并提供重试——两种态不得混用同一文案。
_Avoid_: LRC（实现格式名，不进用户语言）

### 交互

**按压反馈**:
控件被按下时的视觉应答，只表达「点到了」，与按下后是否触发行为无关；设计上不可操作的态不提供按压反馈。
_Avoid_: 点击反馈、触摸反馈

**横滑切页**:
全屏播放器内的左右滑动翻页手势：歌曲页向左滑进歌词页（歌词页在右），歌词页向右滑回歌曲页；顶栏「歌曲 / 歌词」页签与页面状态联动，点击页签同样切换。
_Avoid_: 左滑切页、右滑切页（方向指代不清，一律以目标页表述）

**屏幕常亮**:
歌词页在屏幕上展示且播放进行中（含装载与缓冲）期间的熄屏豁免：屏幕不随系统超时自动熄灭；滑回歌曲页、暂停、关闭全屏播放器、回桌面或锁屏，即恢复系统熄屏节奏，与定时关闭到点暂停自然衔接。不影响手动锁屏。
_Avoid_: 保持唤醒、WakeLock（实现名，不进用户语言）、防锁屏（误导：不影响手动锁屏）、防熄屏

### 本地数据

**最近播放**:
用户点播过的歌曲 ID 记录（最多 50 条），仅存 ID，展示时回后端换取详情。
_Avoid_: 播放历史

**队列快照**:
整个播放队列在持久化时刻的歌曲副本，与播放进度、队列来源一同落盘；App 重启后据此恢复，不回源后端。
_Avoid_: 播放列表快照（「播放列表」为弃用词）

**响应快照**:
接口成功响应的历史留档：在线时静默更新，断网或服务器不可达时回放以维持浏览、搜索与阅读可用（ADR 0012、ADR 0017）。用户不可感知也不可管理。
_Avoid_: 接口缓存（与音频「缓存」家族撞车）、离线记忆、HTTP 缓存（实现机制名，不进用户语言）

**图片缓存**:
列表缩略图与各类封面图片在本机的自动留存：以图片地址为身份、看过即留、容量受限自动淘汰，断网时已留存的图片照常显示；同一地址的内容永不变化（换图必换址）。用户不可感知也不可管理。
_Avoid_: 缓存（泛称，与音频「主动缓存/被动缓存」家族混淆）、HTTP 缓存（实现机制名，不进用户语言）

**主动缓存**:
用户点"下载"后显式拥有的完整音频文件，永不自动驱逐、离线可播，并进入下载列表。用户界面一律称"下载"，不出现"缓存"字样。
_Avoid_: 离线歌曲

**被动缓存**:
播放过程中自动落盘的音频数据，占用不超过缓存预算，自动驱逐，用户不可管理，不出现在下载列表；用户唯一的可见信号是全屏播放器进度条上的缓存染色（见「缓存染色」）。
_Avoid_: 音频缓存（旧名）、智能缓存

**缓存预算**:
被动缓存被允许占用的磁盘空间上限，进程启动时一次性确定、运行期不重算。

**整曲命中**:
装载时刻的被动缓存命中判定口径：SimpleCache 元数据中的 content length（CacheDataSource 打开整文件响应时自动写入，首次播放即有）已知，且该 key 自 0 至该长度全区间缓存命中。该设备从未缓存过或整 key 已被驱逐时元数据缺失，判未命中；部分缓存一律未命中。长度来自本地缓存自学习，不依赖服务端下发。已下载歌曲的本地播放不经此判定，直接计命中（见 backend-next 上下文「访问事实」）。
_Avoid_: 听完标记（重听一遍才打标，已否决——对存量整曲缓存不友好）, fileSize 判定（本上下文无 fileSize）, 部分缓存算命中

**缓存前缀**:
被动缓存中自歌曲起点到首个缓存空洞为止的连续已缓存区间，以缓存元数据的整曲长度为总刻度，跨会话留存；缓存染色与整曲命中均以此为口径。
_Avoid_: 缓冲位置（本次会话的装载进度，另一概念）

**缓存染色**:
全屏播放器进度条上对整曲本地可得与被动缓存进度的静态染色：整曲本地可得（被动缓存整曲命中或已下载）时整槽染浅金，金色是页内唯一暖色且专属此语义；未整曲命中的流式播放态则改以浅藏青条显示缓存前缀位置，随播放实时生长，长满即翻金。已播放段永不染色，金色不覆盖进度语义。
_Avoid_: 缓冲条（显示的不是缓冲而是缓存前缀）

**时长写回**:
App 端对歌曲时长的供给方式：播放就绪后取得真实时长，与列表接口下发的服务器现值比对，不一致才上报写回，fire-and-forget 失败即丢。从未被播放过的歌时长为 0，服务端在线推导按降级口径处理（见 backend-next 上下文「在线状态」）。
_Avoid_: 服务端解析音频元数据（已否决）, 手工维护时长

**缓存升格**:
对已被动缓存的歌曲点"下载"，把被动缓存升格为主动缓存——复用已缓存字节，只补缺失部分。
_Avoid_: 重新下载

**已下载（状态）**:
主动缓存完成的状态；被动缓存的完成度不产生任何可管理状态，唯一可见信号是全屏播放器进度条的缓存染色（见「缓存染色」）。

**下载列表**:
主动缓存完成（含进行中）的歌曲集合，用户据此离线收听。
_Avoid_: 缓存列表

### 收藏

**收藏**:
用户标记喜欢的歌曲集合，仅存于本机、不随账号同步（未登录形态），在「歌曲收藏」页按收藏时间倒序展示。功能图标行与各列表中心形图标的 UI 标签「喜欢」与本词同指。
_Avoid_: 点赞、喜欢列表

### 歌单

**本地歌单**:
用户自建的歌曲集合，仅存于本机、不随账号同步（未登录形态），不设上限、不自动驱逐，按添加顺序收歌。
_Avoid_: 播放列表（弃用词，App 内唯一歌单概念即本词）、收藏夹

**加入歌单**:
功能图标行第四位图标打开的底部浮层，把当前歌曲勾选进本地歌单或从中移出，勾选即时生效；浮层内可新建歌单。
_Avoid_: 添加播放列表、加入播放列表

**我的歌单**:
抽屉入口与页面，以网格展示本地歌单，卡片进入歌单详情。旧称「我的列表」（旧页错读后端策展合集，已重定义）。
_Avoid_: 我的列表

**歌单详情**:
展示某本地歌单内全部歌曲的页面，按添加顺序排列，点歌以整单替换播放队列。

### 评分

**评分**:
用户对当前播放歌曲打的 1–5 星分数，每人每首仅一次、不可改分，归属设备 ID；UI 标签「评分」，由更多菜单进入。
_Avoid_: 打星、平均分（列表中展示的平均星级与评分人数是全体评分的统计，不是单条评分）

**设备 ID**:
本机首次需要时生成的随机唯一标识，持久化于本机、卸载重装即失，用于需要区分设备的服务端行为（评分、访问事实上报等）。
_Avoid_: 用户 ID（App 未登录形态，无账号体系）, UUID（实现细节）, Agent ID（同一概念，demo 的叫法，本上下文统一叫设备 ID）

### 后台生存

**保活**:
维持后台播放不中断的手段统称：播放期间由前台媒体服务维持进程优先级，空闲不驻留；进程被杀后靠下次打开 App 的播放进度恢复兜底（ADR 0014）。
_Avoid_: 常驻保活、守护服务（双层常驻结构已废弃）

**白名单引导**:
App 打开时引导用户到系统电池设置加入电池优化白名单的流程——程序无法代为配置，只能引导。
_Avoid_: 电池弹窗（那是引导的载体，不是流程名）

### 网络

**主用地址**:
客户端访问后端 API 的首选入口，为主域（区别于媒体分发的 CDN 子域）；API 请求与主域歌词文本下载默认走它。
_Avoid_: 服务器地址（泛称）、BASE_URL（实现常量名）

**回退地址**:
主用地址连接层失败（DNS 解析失败、连接被拒、连接超时）时改用的备用入口，为 IP 直连；切换后本次运行期间粘性保持，冷启动恢复主用优先。
_Avoid_: 兜底服务器、备用地址

**服务器不可达**:
手机在线但服务端不可用时的降级态：主用与回退地址均连接层失败、或服务端返回 5xx 时进入；读操作回放响应快照并在后台静默探测，任一请求成功即自动退出。横幅文案「服务暂不可用，展示最近一次内容」（ADR 0017）。
_Avoid_: 服务不可用（那是横幅口吻）、服务器崩了（口语）、断网（那指手机侧无网络）

**媒体混淆**:
CDN 媒体字节在 App 端的还原约定：音频流与图片响应均为服务端 +31 混淆后的字节，播放数据源与图片加载链路统一 -31 还原（仓库级 ADR 0011）；本地被动缓存与已下载文件保存还原后的明文。与歌词解密（AES）是两套独立变换。
_Avoid_: 解密（混淆无密钥，还原即还原）、媒体加密

### 浏览

**底部导航栏**:
一级页面底部的 4 Tab 导航（首页 / 最近播放 / 分类 / 最新歌曲），中央凸出「我的下载」圆钮。
_Avoid_: 导航栏（泛称，须区分是底部导航栏还是侧边抽屉）、底部菜单

**侧边抽屉**:
顶栏菜单按钮打开的侧滑面板，聚合全部页面入口。
_Avoid_: 导航栏、抽屉菜单

**热门歌曲（Trending）**:
首页展示的歌曲榜单，按近一个月的播放量聚合排序。
_Avoid_: 排行榜（后端没有榜单实体，只是读取侧的排序视图）

**音乐专辑页**:
侧边抽屉「音乐专辑」入口对应的页面，以专辑卡片网格展示全部专辑；点击卡片进入专辑歌曲页。
_Avoid_: 专辑列表页、专辑页（泛称）

**专辑卡片**:
音乐专辑页与分类专辑页中一张专辑的展示单元：专辑图在上（方形圆角图，中央播放钮浮层），专辑名在图外下方，两者不同框。点击进入专辑歌曲页。
_Avoid_: 专辑格子

**专辑歌曲页**:
展示某张专辑下全部歌曲的详情页，由音乐专辑页或分类专辑页的专辑卡片进入（分类下仅一张专辑时由分类专辑页直跳），顶栏标题为专辑名。

**分类列表页**:
底部导航「分类」Tab 对应的页面，以一排 3 个圆形分类图加圆下名称的网格展示全部分类；圆内文字由后台上传的分类图素材自带，App 不叠字。音乐分类点击进入分类专辑页，书籍分类点击进入书籍列表页。
_Avoid_: 分类页（泛称）

**分类专辑页**:
展示某个分类下全部专辑的网格页，由分类列表页进入；分类下仅有一张专辑时不展示此页，直接进入该专辑的歌曲页，返回时回到分类列表页。
_Avoid_: 分类歌曲页（分类已下放专辑而非歌曲，该页面已废弃）

**搜索**:
一次提交一个关键词，同时按歌名、专辑名与艺术家名三路匹配的检索。
_Avoid_: 查找、找歌

**搜索页**:
顶栏搜索图标进入的页面，顶部搜索框加组合结果分段展示（歌曲、专辑、艺术家，空段不展示）；歌曲段提供「查看更多歌曲」进入歌曲结果页。
_Avoid_: 搜索结果页（泛称，指代不明）

**歌曲结果页**:
搜索页歌曲段「查看更多歌曲」进入的页面，按歌名匹配全量分页列出歌曲，顶栏标题为搜索关键词。

**艺术家**:
后台维护的演唱者实体，有自己的头像；搜索结果段之一，点击进入艺术家歌曲页。歌曲行副标题里的歌手只是歌曲上的文本，不是本实体。
_Avoid_: 歌手（那指歌曲上的文本）、演唱者

**艺术家歌曲页**:
展示某艺术家名下全部歌曲的页面，由搜索结果艺术家行进入，顶栏标题为艺术家名；重名艺术家共用此页。

### 阅读

**书籍**:
以章节组织的可阅读文本内容实体，归属书籍分类，与歌曲互不隶属；由分类列表页的书籍分类入口进入。
_Avoid_: 小说（书籍不全是小说）、电子书（泛称）

**书籍列表页**:
展示某书籍分类下全部书籍的页面，由分类列表页的书籍分类入口进入；从书籍直接进入阅读页。

**章节**:
书籍按序划分的内容单元，是阅读跳转与正文加载的最小单位。
_Avoid_: 回目、篇

**目录**:
阅读页顶栏按钮唤起的底部浮层，滚动列出全书章节，当前章高亮，点选即跳、浮层收起。
_Avoid_: 章节列表（口语可用，正式用目录）、选章

**拖动翻章**:
阅读页滚到章尾后继续上拖、或滚到章首后继续下拖，松手越过阈值即翻入下一章/上一章的手势；拖动中章尾/章首提示文案随是否达到阈值切换，章首「上一章」与章尾「下一章」链接保留。
_Avoid_: 边界加载（不把下一章正文拼接到本章，仍是整章跳转）、下拉刷新

**滑动翻章**:
阅读页内水平滑动换章的手势：左滑进入下一章、右滑回到上一章，与主流阅读 App 及全屏播放器「横滑切页」方向一致（ADR 0013）。
_Avoid_: 左滑/右滑翻章（方向指代不清，一律以目标章表述）、翻页（翻的是章不是页）

**阅读设置**:
阅读页顶栏「Aa」按钮唤起的底部浮层，聚合阅读偏好调节（字号与背景色，全局一份偏好，不分书）。
_Avoid_: 字体设置、字号设置

**阅读进度**:
某书籍上次读到的章节与章内位置，仅存于本机、不随账号同步（未登录形态），重进书籍即续读。
_Avoid_: 阅读历史（不存在历史列表概念）、书签（另一概念，当前没有）

**书籍分类**:
分类的两个类型之一，下挂书籍而非专辑（另一类型为音乐分类，下挂专辑），与音乐分类混排于分类列表页。
_Avoid_: 书分类、书城

### 品牌

**应用图标**:
设备启动器上代表本 App 的识别图：白圈内蓝底、衔橄榄枝的白色和平鸽。区别于应用内 UI 图标（如功能图标行）；当前无系统通知图标。
_Avoid_: logo（泛称）、启动器图标（实现术语）
