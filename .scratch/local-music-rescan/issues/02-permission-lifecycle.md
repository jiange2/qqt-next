# 02: 授权生命周期完善

**What to build:** 把音频权限的完整生命周期做成显式的页面状态。拒绝授权时，本地音乐页显示解释空态和「重试」「去系统设置」入口，重试能再次拉起授权；权限在系统设置里被撤销后，再进页面不是空列表假装没歌，而是旧列表灰显加重新授权横幅——歌没丢，只是权限没了；重新授权成功后自动刷新，灰显的行恢复可播。

**Blocked by:** 01: 授权即全库：MediaStore 扫描核心闭环.

**Status:** resolved

- [ ] 拒绝授权 → 解释空态 + 重试/去系统设置入口；重试可再次拉起授权弹窗
- [ ] 授权后到系统设置撤销权限 → 再进页面旧列表灰显 + 重新授权横幅，列表不放空
- [ ] 重新授权成功 → 自动刷新，灰显行恢复可点可播
- [ ] Android 13+ 申请的是音乐粒度权限；旧权限仅在 Android 12 及以下声明
