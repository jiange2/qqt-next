# 本地歌曲播放器功能图标行整行移除（纯播放形态）

Status: ready-for-agent

> 延续「本地歌曲播放器只留播放设置」（f6f72fa）的收敛：那次收起喜欢 / 下载 / 加入歌单三个图标，本次把本地歌曲仅剩的两个（播放设置 / 更多）也去掉，本地歌曲播放页进入纯播放形态。不推翻任何 ADR：ADR 0007（评分身份与更多菜单可扩展列表）在线分支原样保留，ADR 0020（元数据覆盖层）与列表长按编辑入口不动。

## Problem Statement

本地歌曲的全屏播放页在标题区与进度条之间还留着两个功能图标（播放设置 / 更多），用户觉得碍眼。本地歌曲的收藏 / 歌单 / 评分 / 下载本就无意义，播放设置（仅定时关闭）与编辑信息也都有页外路径或可放弃，这两个图标没有留在页面上的必要。

## Solution

播放本地歌曲时功能图标行整行不出现：标题区之下直接是进度条，页面只保留封面 / 标题 / 进度 / 主控行等纯播放元素。在线歌曲的五图标行（喜欢 / 播放设置 / 下载 / 加入歌单 / 更多）原样保留。定时关闭不新增替代入口：已设的定时在本地播放期间继续全局生效（不可见、不可取消，切回在线歌曲恢复可见可操作）。编辑信息只保留列表长按入口（本地音乐页歌曲视图 / 本地专辑页长按歌曲行），播放器侧的编辑接线整体拆除。不新增任何隐蔽入口、不改布局常量、不落盘。

## User Stories

1. 作为本地音乐听众，我希望播放本地歌曲时标题区与进度条之间没有任何图标，以便页面干净、不碍眼。
2. 作为本地音乐听众，我希望本地播放页只剩封面 / 标题 / 进度条 / 主控行等纯播放元素，以便注意力回到播放本身。
3. 作为在线歌曲听众，我希望在线播放页的五图标行（喜欢 / 播放设置 / 下载 / 加入歌单 / 更多）完全不变，以便既有操作不受影响。
4. 作为混合队列听众，我希望队列在本地歌与在线歌之间切换时图标行随之消失 / 恢复，以便形态始终与当前歌曲匹配、无残留。
5. 作为本地音乐听众，我希望在本地音乐页歌曲视图或本地专辑页长按歌曲行仍能编辑元数据，以便整理需求有页外路径。
6. 作为本地音乐听众，我希望长按编辑保存后正在播放的本地歌曲标题 / 歌手 / 封面即时刷新，以便所见即所得（现有行为不变）。
7. 作为定时关闭用户，我希望在线歌曲上设的定时在切到本地歌曲后继续生效、到点照常暂停，以便定时不因切歌失效。
8. 作为定时关闭用户，我接受本地播放期间看不到定时角标也无法取消，以便页面保持干净；切回在线歌曲即恢复可见、可取消。
9. 作为在线歌曲听众，我希望更多菜单里的评分（含评分对话框、已评分兜底）原样可用，以便评分链路不受影响。
10. 作为本地音乐听众，我希望本地歌曲依旧没有歌词页、播放期间不发 song_info 请求，以便既有口径不变。
11. 作为本地音乐听众，我希望进度条缓存染色（本地直读整槽浅金）、主控行、队列浮层、播放模式全部照旧，以便纯播放元素不受牵连。
12. 作为正常屏用户，我希望本地播放页依旧固定高度、整体不可拖动（无微滚动），以便布局不变性保持。
13. 作为矮屏用户，我希望放不下时仍整体滚动托底、主控行钉底，以便兜底行为不变。
14. 作为本地音乐听众，我希望正在播的本地歌即使媒体库行已消失（文件被删等）播放页也不出错，以便边界场景稳定（整行不渲染后原「找不到记录收起入口」判定自然消失）。
15. 作为维护者，我希望播放器不再持有本地音乐快照与编辑面板接线，以便死代码整段拆除、不留半截入口。
16. 作为维护者，我希望 CONTEXT.md 与 ui.md 的词条口径同步更新，以便文档与实现一致。

## Implementation Decisions

### 功能图标行（grilling Q1：仅本地分支）

- 功能图标行整行以「非本地歌曲」为渲染条件：本地歌曲时整行不组合；在线歌曲五图标行原样（SpaceBetween、28dp 图标 / 48dp 触控框 / 行 padding 18dp 等全部不动）。
- 行内原有的本地分支一并简化：本地居中排列（spacedBy 40dp）分支删除，行内各图标的 `isLocalSong` 守卫随整行条件收敛，不留冗余判断。
- 下载四态、喜欢切换、加入歌单浮层、定时角标等在线行为零改动。

### 更多菜单收敛为在线专用

- 「编辑信息」菜单项删除；更多图标只出现在在线分支，原「本地歌且快照找得到记录才出现」守卫删除。
- 浮层内评分项的 `!isLocalSong` 兜底守卫可一并删除（浮层只由在线分支打开）；可扩展列表结构保留（ADR 0007），评分对话框与已评分兜底不动。

### 播放器侧编辑接线拆除

- PlayerScreen 拆除：`editingSong` 状态、页内 `LocalMetadataEditSheet` 渲染、`localMusicViewModel` 参数、`localSongs` / `localSong` 快照查回逻辑，全部删除。
- AppNavigation 播放器调用点去掉 `localMusicViewModel` 传参并更新注释；`LocalMusicViewModel` 仍提升在导航层（列表长按编辑 / 排除 / 删除等共用），不受影响。
- `PlayerIcons.Edit` 全仓仅播放器更多菜单一处引用，随之删除；在途批量编辑特性若需铅笔图标届时自行重加。
- 列表长按入口（LocalMusicScreen / LocalSongRow → LocalMetadataEditSheet）零改动，面板本身与保存后刷新机制不动。

### 定时关闭去留（grilling Q2 / Q3）

- 彻底移除本地播放期间的定时入口，不新增任何替代入口（长按封面 / 顶栏图标等一律不做）。
- PlayerSettingsManager 与定时行为零改动：定时是会话级全局设置，在线歌上设好后本地播放期间继续生效、到点暂停。
- 角标仍挂播放设置图标（随在线分支渲染）：本地播放期间定时不可见、不可取消，切回在线歌曲恢复可见可操作——该「不可见但仍生效」状态经确认接受，不为它加额外指示。

### 布局

- `fixedContentHeight` 保守估算与四段间距最小值均不改：本地行消失腾出的约 48dp 由 weight 间距吸收，正常屏内容恒等于视口、整体不可拖动的不变性保持，矮屏滚动托底不变。宁大勿小的估算口径延续，不为本地态单设估算分支。

### 文档与 ADR

- CONTEXT.md 同步：「功能图标行」词条（本地歌曲整行不出现）、「播放设置」词条（入口仅在线播放时存在；本地播放无入口、已设定时仍全局生效）、「更多菜单」词条（仅在线歌曲评分，删本地「编辑信息」口径）；涉及播放器编辑入口的相邻词条一并核对。
- android/doc/ui.md 同步：PlayerScreen 节与本地歌曲差异节、元数据编辑入口数（两处 → 仅列表长按）、LocalMusicViewModel 共用说明去掉播放器编辑信息。
- 不新增 ADR：可逆的 UI 收敛，无架构推翻；三条门槛（难以反转 / 无上下文会让人惊讶 / 真实取舍）均不成立。历史 spec 与 ADR 归档不改写。

## Testing Decisions

- 纯 UI 移除，无新数据接缝：可见性判定继续内联在 Composable，不抽取纯函数（本仓 JVM 单测先例全部在 data/local 数据层，UI 分支判定无测试先例，抽取属过度设计）。既有单测不受影响。
- 沿用视图切换 spec 先例：本仓维持手工验收（AI 不编译、不跑 gradlew），设备级验收清单见票据 01，待人工编译后真机逐项确认。

## Out of Scope

- 在线歌曲五图标行的任何改动（喜欢 / 播放设置 / 下载四态 / 加入歌单 / 更多评分）。
- 任何替代入口：长按封面、顶栏图标、手势、设置页等一律不做。
- 定时关闭行为、角标机制、PlayerSettingsManager 的任何改动。
- 编辑面板本身、列表长按入口、覆盖层写入机制（ADR 0020）。
- 歌词页 / song_info 请求口径（本地歌曲本就没有歌词页）。
- 缓存染色、主控行、队列浮层、播放模式、迷你播放器。
- 布局常量调整（fixedContentHeight、间距最小值、封面上下限）。
- 批量管理特性（在途 .scratch/local-music-batch-edit/，独立实现）。

## Further Notes

- grilling 四决策（2026-11-14 用户全部确认）：Q1 仅本地分支移除；Q2 定时入口彻底移除不留替代；Q3 接受本地播放期间定时不可见但仍生效；Q4 编辑信息只留列表长按。
- 与在途批量编辑 spec（ready-for-agent）正交：那是列表级编辑模式（LocalMusicScreen / LocalSongRow），本特性是播放器级入口移除（PlayerScreen / AppNavigation / PlayerIcons）。唯一交点是 PlayerIcons.Edit（本 spec 删除、其需要时重加）与 LocalMetadataEditSheet 的共用说明文案（各自更新所在段落）。实现时以届时分支最新状态为基线。
- 本次移除后本地歌曲播放页无任何功能图标，「更多菜单」「播放设置」对本地歌曲不再可达——这是决策结果而非遗漏。
