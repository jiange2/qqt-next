# 03: AliyunApi 接缝与今日累计

**What to build:** 端上直连阿里云 OpenAPI 能取回「账号今日累计」。签名手写 RPC v1（HMAC-SHA1），公共参数齐全，`Timestamp` 用 UTC、`SignatureNonce` 每次唯一，请求与响应都有超时。`DescribeDomainTrafficData` 不传 `DomainName`（账号全量）、`Interval=300`、时间窗为北京时间今天 00:00 至请求时刻。四类错误归一为领域状态：鉴权失败→「凭证失效」、无权限→「权限不足」、`Throttling`→指数退避有限次后按网络错误、网络/超时→「网络错误」；任何单账号错误不影响其他账号。看板卡片显示今日累计与「截至 HH:mm」（北京时间，未结算口径）。刷新编排：打开、下拉、前台每 5 分钟（读设置间隔）各触发一次；退后台取消定时器。UI 与 ViewModel 只依赖 `AliyunApi` 接口，不拼参数、不解析 JSON。
