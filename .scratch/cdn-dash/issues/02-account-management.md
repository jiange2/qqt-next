# 02: 账号管理与加密落盘

**What to build:** 使用者能在设置页新增账号（自起名称 + AccessKeyId + AccessKeySecret）、删除、启用/停用、拖拽排序；看板按手动顺序只列启用账号，顺序不随流量变化。密钥只存本机且加密：Keystore 中生成不可导出的 AES-GCM 密钥，密文 base64 进 DataStore，删除账号同时清除密文与快照，密钥不进日志/备份/导出。设置页同时落「刷新间隔」与「关于」两项（刷新间隔供票据 03 读取，关于展示版本与「凭据存在本机」说明）。AccountStore 是唯一持久化接缝：调用方只传明文、不见密文。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 新增账号后看板立即出现该账号卡片壳（名称正确），停用后从看板消失、启用后回来
- [ ] 删除账号后其密文与快照不再存在；仅删除 UI 条目不算完成
- [ ] 拖拽排序持久化，重启应用后顺序保持；流量大小不影响顺序
- [ ] 同名/空名称/空 key 的输入按表单校验拒绝并给出提示
- [ ] AccountStore 用内存实现替换后有 JVM 测试：保存后读回一致、删除后不存在、快照带抓取时间（本机不开编译，测试照写）
- [ ] Keystore 真实加解密与「删除不留残留」列入人工验收清单
- [ ] 设置页有刷新间隔选择项（默认 5 分钟）与关于页内容；生物识别开关留出条目位置（实现归 09）
