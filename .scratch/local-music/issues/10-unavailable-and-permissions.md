# 10: 文件不可用与授权失效

**What to build:** 文件在扫描后消失或无法读取时，用户看到的是该行灰显加提示，而不是整页清空；文件夹授权被系统回收时，用户看到明确的重选引导，而不是以为歌丢了。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 点播已删除或不可读的文件时，提示「文件不可用」，该行灰显且不可点
- [ ] 文件不可用不会自动触发扫描，也不影响其它歌曲播放
- [ ] 下次重新扫描时，已不存在的文件从列表移除
- [ ] 进入本地音乐页时检查所有根目录的持久化授权
- [ ] 全部授权失效时展示重新选择目录的空态与主按钮
- [ ] 部分授权失效时给出提示，并提供管理音乐文件夹入口，对应歌曲灰显
- [ ] 重新授权成功后，对应歌曲恢复可播，不需要重装或清数据
- [ ] 授权检查不阻塞页面首帧
