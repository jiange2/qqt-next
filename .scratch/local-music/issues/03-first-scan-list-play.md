# 03: 首次授权文件夹 → 扫描 → 歌曲视图 → 播放

**What to build:** 用户通过系统目录选择器授权一个音乐文件夹后，App 自动扫描并把可播放的音频列成歌曲视图；点歌以当前完整列表为播放队列，来源记为本地音乐，播放模式按该来源单独记忆。这是本地音乐的第一条完整链路（扫描结果暂存内存，跨重启保留由后续票负责）。

**Blocked by:** 01、02

**Status:** resolved

- [x] 选目录时使用系统目录选择器，授权被持久化，全程不申请任何存储权限
- [x] 授权后自动开始扫描，界面展示扫描进度，可取消
- [x] 只收 `mp3 / m4a / aac / flac / ogg / opus / wav`；跳过隐藏目录/文件与含 `.nomedia` 的目录；不限深度
- [x] 标题、艺术家、专辑、专辑艺术家、音轨号、年份、时长从文件标签读取；无标题时回退为去掉扩展名的文件名
- [x] 内容完全相同的两份文件在列表中只出现一条
- [x] 歌曲视图按标题升序，使用中文排序规则
- [x] 点击歌曲开始播放，队列为当前完整歌曲列表
- [x] 在本地音乐里切换播放模式，不影响在线专辑、收藏、下载列表的来源记忆
- [x] 扫描过程中退出页面再进入，不会叠加出第二次扫描

## Answer

新增 `data/local/` 三个文件：`LocalMusicRoot`（从 UI 包移到数据层，供扫描与后续持久化共用）、`LocalSong` + `LocalSongTags`（身份指纹、标签快照、`displayTitle()` 等展示值兜底、`toSong()` 转播放模型）、`LocalMusicScanner`（SAF 遍历 + 指纹 + 标签）。扫描全程在 `Dispatchers.IO`、逐文件串行读 `MediaMetadataRetriever` 与首尾各 32KB 的 SHA-256，每处理一个候选文件就 `ensureActive()`，取消即中止；目录层用队列 BFS，不限深度，跳过以 `.` 开头的目录/文件，目录自身直接含 `.nomedia` 时整棵子树不入队（子树里的文件自动跳过），音频扩展名白名单大小写不敏感，结果按 `Collator.getInstance(Locale.CHINA)` 比较展示标题升序。指纹含文件大小；provider 不给 size 时退化为全文哈希，避免把两份不同文件算成同一首。内容相同的副本按指纹去重，保留先扫到的一条。

`LocalMusicViewModel` 从 `ViewModel` 改为 `AndroidViewModel`，状态扩为 `roots` / `songs` / `scan` 三条 StateFlow：`addRoot` 持久化授权（`takePersistableUriPermission`，同一棵树只记一次）后立即扫描；`startScan` 同一时刻只允许一个任务，扫描期间再来的请求记一次「结束后补跑」（扫描中又加目录也能被扫到，且不会两个任务同时遍历）、完成才整体替换索引，取消或失败保留上一次完整结果；`cancelScan` 取消当前任务。进度节流到每 100ms 一次，避免主线程被逐文件的进度重组刷满。`LocalScanState` 多一个 `cancelled` 标记：首次扫描就取消时页面显示「扫描已取消 + 重新扫描」，不当成「目录里没有音乐」。

UI：`LocalMusicScreen` 按五态切换 —— 未授权引导空态 / 首次扫描整页进度（文件名 + 已处理文件数 + 已找到首数 + 取消）/ 扫描已取消 / 授权但结果为空（提示支持的格式 + 重新扫描）/ 歌曲列表（重扫期间顶部一条进度条，旧列表照常可点播）。本地歌曲行是新写的 `LocalSongRow`（序号 / 标题 / 艺术家 / 时长，当前曲目转橙），没有复用在线列表行——在线行的播放、下载计数对本地歌曲没有意义。顶栏菜单的「重新扫描」随扫描管线接入启用，扫描中同一位置变成「取消扫描」。

播放：`QueueSource` 新增 `LOCAL = "local"`（键空间由五键扩为六键，注释同步），点歌时 `playSong(song, songs.map { it.toSong() }, QueueSource.LOCAL)`，队列即当前完整列表，来源记忆按 `local` 单独存，不影响专辑 / 收藏 / 下载列表。`Song` 的 id 为 `local:<指纹十六进制>`、url 为文件 content URI、时长为秒；`PlayerViewModel` 改用它 `data.local` 里的 `LOCAL_SONG_ID_PREFIX`，不再各自持有一份字面量。

不在本票：索引与覆盖层持久化（05）、增量重扫与「新增 x 首、移除 y 首」（06）、专辑视图与封面（08）、元数据编辑（09）、根目录移除 / 授权失效引导（07、10）、播放器入口差异化（04）。

未新增自动化测试：spec「Testing Decisions」已确定本功能不新增测试，验收走手工清单；本地无 Android SDK（无 `ANDROID_HOME`/`local.properties`），未做编译验证（与票据 01、02 同）。手工验收重点：选目录后自动出歌、扫描中取消后列表回到上一次完整结果、同内容副本只出现一条、无标签文件回退文件名、本地里切随机不影响在线专辑的模式、扫描中切页回来只有一个扫描在跑。
