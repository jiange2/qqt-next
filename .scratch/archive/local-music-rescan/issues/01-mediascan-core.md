# 01: 授权即全库：MediaStore 扫描核心闭环

**What to build:** 打开本地音乐页，出现一句说明和「授权音乐访问」按钮；授权走系统标准的音频权限弹窗，授权后立刻（秒级）看到全机音乐的歌曲列表——标题中文排序、无标题标签以文件名兜底、无专辑标签以文件夹名兜底成组。点歌以当前列表整体入队可播，杀掉 App 重启后快照直出列表、播放队列与进度可恢复。进入页面时库静默刷新一次，顶栏「重新扫描」完成后提示「新增 x、移除 y」，全程没有进度条也没有取消。长按编辑信息的六字段编辑改挂新歌曲身份、跨重扫保留、可恢复默认、改专辑信息即时换组。扫描来源换成系统媒体库（`IS_MUSIC` 全库查询，多存储卷合并），歌曲身份从内容指纹换成媒体库行 ID（`local:` 播放命名空间与本地歌曲判据不变）；旧升级数据（按指纹记的索引与覆盖层）首次启动直接丢弃。SAF 目录授权、目录重叠拒绝、扫描进度/取消的整套旧 UI 与旧代码一次性移除（消费方只有本地音乐页，一刀替换）；覆盖层、播放接入、离线判据等既有机制沿用。

**Blocked by:** None (can start immediately).

**Status:** resolved
