# 媒体文件存储在服务器本地文件系统

音频（`uploads/`）、封面与横幅（`images/` + `images/thumbs/`）、歌词（`lrc/`）全部存储在 Web 容器的本地目录，由 Apache 直接以静态文件形式对外提供，数据库只保存文件名。

决定维持本地文件存储，理由：项目为单实例部署，本地存储实现最简单，且与模板自带的上传/缩略图逻辑（`uploadscript.php`、`thumbnail_images.class.php`）无缝配合。迁移到对象存储（OSS/S3）需要重写全部上传与 URL 拼接逻辑，目前无此需求。

**约束**：此决定锁定了单实例部署形态。一旦需要横向扩展多容器实例，必须先完成对象存储迁移——`uploads/` 等目录的可写权限（`chown www-data`）与文件名时间戳防重名逻辑都是基于本地盘的假设。
