# 保留逗号分隔的关联字段，不做关系表规范化

专辑与艺术家的关联（`tbl_album.artist_ids`）、横幅与歌曲的关联（`tbl_banner.banner_songs`）、以及歌曲的艺术家字段（`tbl_mp3.mp3_artist`）都以逗号分隔字符串存储，查询侧用 `FIND_IN_SET` 或 `IN (...)` 处理，删除实体时不会级联清理这些引用。

这是采购模板的原始设计。规范化成标准关联表需要改动后台表单、`api.php` 中所有相关查询分支和 `processData.php` 的删除逻辑，改动面大且模板后续更新会产生冲突；当前内容量级下 `FIND_IN_SET` 的性能损失可以接受。决定：**维持现状**。新增类似的多对多关联时，优先使用关联表（如已有的 `tbl_playlist_songs`），不要继续复制逗号串模式。
