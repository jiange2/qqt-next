# Backend

管理音乐内容并向 Android 客户端分发数据的内容管理上下文。管理员通过 Web 面板维护内容，App 通过 `api.php` 消费内容。

## Language

### 内容实体

**Song（歌曲）**:
可播放的音乐条目，是系统的核心实体。一首歌曲属于一个分类，可以关联艺术家与专辑。
_Avoid_: MP3、曲目、Post（历史遗留命名，领域上它就是歌曲）

**本地歌曲**:
音频文件托管在平台自己服务器上的歌曲。
_Avoid_: 上传歌曲

**外链歌曲**:
音频指向外部地址（YouTube 或其他站点）的歌曲，平台不存储其音频。
_Avoid_: 在线歌曲、链接歌曲

**Category（分类）**:
按题材对歌曲做的横向划分（如「华语流行」），一首歌曲只属于一个分类。
_Avoid_: 标签、类型（「类型」在本上下文中保留给本地/外链之分）

**Artist（艺术家）**:
演唱或创作歌曲的人或团体。
_Avoid_: 歌手、明星

**Album（专辑）**:
艺术家发布的歌曲合集，可关联多位艺术家。
_Avoid_: 唱片

**Playlist（播放列表）**:
由管理员策展的歌曲合集（如「经典老歌」），通过关联表收录歌曲。
_Avoid_: 歌单（口语可用，正式场合用播放列表）；**注意**：与 Android 端的「播放队列」是不同概念

**Banner（横幅）**:
首页轮播位的运营内容，可挂接一组歌曲或一个外部链接。App 用户点击后进入以横幅标题为题的歌曲页，展示挂接的歌曲组；未挂歌时跳转外链。
_Avoid_: 轮播图、广告位

### 状态与运营

**上架 / 下架**:
内容是否对 App 可见的状态。下架是隐藏而非删除。
_Avoid_: 启用/禁用（避免与用户账号的状态混淆）

**热门歌曲（Trending Songs）**:
按播放量排序的歌曲集合，用于首页推荐。
_Avoid_: 趋势歌曲

**播放量**:
歌曲被收听/查看详情的累计次数，是热门排序的依据。

### 用户行为

**App 用户**:
通过 App 注册/登录的终端用户，用于收藏、评分等行为。与「管理员」是完全独立的两类账号。
_Avoid_: 会员、客户

**管理员（Admin）**:
通过后台面板登录、管理内容的运营人员账号。
_Avoid_: 超管、运营

**收藏（Favourite）**:
App 用户标记喜欢的歌曲，可反复切换（收藏/取消收藏是同一次操作）。
_Avoid_: 点赞、喜爱

**评分（Rating）**:
App 用户对歌曲打的 1–5 星分数，每人对每首歌仅一次。

**举报（Report）**:
App 用户对问题内容的投诉记录，待管理员处理。

**歌曲建议（Song Suggest）**:
App 用户希望平台收录的歌曲推荐，待管理员审核。
_Avoid_: 点歌、投稿

### 媒体与配置

**LRC 歌词**:
带时间轴的歌词，可内嵌于歌曲（文本），也可作为独立文件存放。

**缩略图（Thumbnail）**:
封面图上传时自动生成的列表用小图，与原图同名存放。
_Avoid_: 小图

**全局设置**:
系统唯一一份的全局配置（应用名、包名、推送凭据、分页条数等），修改即时生效于所有 API 请求。
_Avoid_: 配置、参数
