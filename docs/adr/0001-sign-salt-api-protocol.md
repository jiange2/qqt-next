# 单入口 API + sign/salt 签名协议

后端所有对 App 的接口集中在 `api.php` 一个入口，请求体为 `base64(urlencode(json))`，鉴权依赖 `package_name` 比对和 `sign = md5("viaviweb" + salt)` 签名，响应统一包裹在 `ONLINE_MP3` 根节点下。

这套协议继承自项目采购的 viaviweb 模板，Android 端与后端均已按此实现。它并非现代意义上的安全方案（密钥硬编码在客户端、不防重放、MD5 无盐），换成标准 REST + HMAC/JWT 需要两端同时重写并协调发版，收益不足以覆盖成本。因此决定：**维持现有协议原样，任何新接口沿用相同的编码与签名方式**；未来若重构，必须作为一次两端同步的专项迁移来做，而不是一侧单独演进。
