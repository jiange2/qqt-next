# API 入口域名优先、IP 回退兜底

后端 API 入口从 IP（`http://101.132.159.145:8001/`）迁移到域名 `http://qqt.yunshangzhiai7.top:8001/`。为对冲域名侧故障（DNS 解析、反代），客户端保留原 IP 作为回退：`ApiClient` 的 OkHttp 应用拦截器在主域请求遭遇连接层失败（DNS 解析失败、连接被拒/主机不可达、连接超时）时，把请求 host/port 整体改写为回退地址重试一次；切换进程内粘性——本次运行期后续主域请求直接走回退，冷启动恢复域名优先。仅覆盖 API 请求与主域歌词文本下载；歌曲/封面是后端下发的绝对 URL（CDN 域、旧 prod IP），不参与切换。主用与回退均带端口 8001，端口契约延续 ADR 0004（换端口 = 发版）。

## Considered Options

- **自定义 `Dns` 映射回退**：被拒——只能兜住 DNS 解析失败，覆盖不了「解析成功但连不上」（最常见的实际故障形态）。
- **双 Retrofit 实例、业务层手动切换**：被拒——侵入 `MusicRepository` 每个方法；拦截器单点收口。
- **每个请求都先试域名再试 IP**：被拒——域名故障期每个请求都多付一次连接失败延迟；进程内粘性只付一次。
- **读超时/HTTP 错误也触发切换**：被拒——读超时说明后端在响应但慢，同源 IP 同样慢，切换只会放大延迟；4xx 是业务/签名错误，换入口结果相同。连接超时与读超时靠异常消息区分（消息含 "connect" 判为连接超时，"read timed out" 不切换）。

## Consequences

- `network_security_config.xml` 增放主域明文 HTTP（媒体明文白名单见 ADR 0005）；回退 IP 原有放行条目保留。
- API 客户端连接超时显式收紧为 5s（读超时保持默认）：域名「解析成功但连不上」时首个失败请求的等待减半；读超时不可收紧——`album_songs` 一次全量返回 2000 条（ADR 0007）。
- 主用/回退地址均为编译期常量：换入口 = 发版，延续 ADR 0004 口径。
