# CDN 看板的「最近一年花费」按账期如实呈现，不做预付费摊销

花费取 `QueryAccountBill`（BSS OpenAPI）：按月、全产品合计、`PretaxAmount`（应付金额）。预付费 CDN 流量包在下单当月一次性计入，因此某些月份会出现尖峰。看板如实反映，不做任何平滑——这是唯一能与阿里云账单逐月对得上的口径。

## 决策

1. **范围**：账号全部产品，不按 ProductCode 过滤；主数字是 `PretaxAmount`，明细再拆现金（`CashAmount`）与代金券（`DeductedByCashCoupons`）。
2. **周期**：最近 12 个已出账的完整月，当月不显示（当月账单未出，任何估算都与账单不符）。
3. **不摊销**：预付费资源包按账期计入，不按有效期分摊到各月。
4. **不做「含税」表述**：接口无税额字段，界面只写「应付金额」。
5. **按需加载**：12 个月 = 每账号 12 次调用，花费页独立按需拉取并本地缓存 24 小时，不进入首屏请求路径。

## Considered Options

- **摊销口径**：被否——会得到与账单对不上的自制数字，一旦被拿去做预算依据就无法审计。
- **只统计 CDN 产品**：被否——使用者要看「账号总支出」，流量成本只是其中一块。
- **显示当月预估**：被否——`DescribeCdnUserBillPrediction` 只覆盖 CDN 预测，与「全产品支付金额」不是一回事，混用会误导。
- **按天（`Granularity=DAILY`）画年度曲线**：被否——365 次调用，展示价值低于成本；年度视图按月即可。

## Consequences

- **尖峰需要解释**：买包的月份柱子会很高，界面必须在该月标注「含预付费资源包」，否则读数会被误判为超支。
- **权限门槛**：`bss:QueryAccountBill` 与 CDN 只读是两套权限，未授权的账号在花费页显示「费用权限未开启」，不影响流量与资源包视图。
- **分拆型产品不影响合计**：官方注明 CDN 属分拆型产品，分拆项需查分账账单；本看板只要账号合计，故不涉及。
