# 书籍阅读域：分类类型化与章节存库

产品从纯音乐扩展出书籍阅读：入口复用分类列表页，新增「书籍分类」与音乐分类混排。决策有二：**分类表加类型字段而非独立书籍分类域**（`categories.type`，`music`/`book`，存量全部迁移为 `music`）；**章节正文存数据库而非 OSS 文件**（新增 `Book` + `Chapter` 两表）——正文是小体量纯文本，走库可一次请求取一章，免除文本媒体在 CDN 防盗链 Referer 上的特殊处理，管理面板也能直接逐章编辑。对 App 的协议变更经遗留协议门面新增方法，两端同步发版（门面策略评审），不留旧版兼容（先例：ADR 0009 删 `cat_songs`）。

## 模型变更

- `Category.type`: `music`（默认）/ `book`。书籍分类下挂书籍而非专辑；归属链（歌曲 → 专辑 → 分类，ADR 0009）不变，书籍不参与该链。
- `Book`: `categoryId`（必填，单值）、`categorySort`（维度顺序第三维度，见 ADR 0007 范式）、`name`、`author`、`cover`（媒体 Key）、`status`——可见性语义与专辑一致：书籍不可见即其章节对 App 不可见。无简介字段：App 无书籍详情页，简介没有展示位。
- `Chapter`: `bookId`、`title`、`content`（正文全文）。章节不设排序字段，展示序即 id 序（录入/切分顺序天然正确，不支持章节重排）；不独立上下架，可见性完全随书。
- 删除约束：仍有书籍的分类阻止删除（对齐 ADR 0009 专辑规则）；删书级联删章节。

## 录入通道

管理面板双通道：**逐章录入**（手动建章、逐章编辑正文）与**智能分章节**（上传整本 TXT，后端按章节标记正则族切分，先展示章标题清单预览、确认后才入库；识别不出的行并入上一章；整本无标记收作单章「正文」）。TXT 导入仅章节管理页一个入口（新建书籍保存后跳转该页）；重复导入为覆盖替换——删旧写新单事务，强确认弹窗列明删 N 章、写 M 章。切分标记族（v2，按馆藏 7 本真实书籍核查扩充）：「第X章/回/节/篇/辑/讲/函/首/话/谈」行首与二字后缀「次谈话/封信」（中文/阿拉伯数字，数字集补廿/卅与大写数字）、固定词章（序章、序言、引言、引语、楔子、前言、后记、尾声、终章、番外、目录、译者序、译序、新版说明）、前置量词行首（「函一」）、数字+标点短行（「001→试探」「1、我今日歌唱」）、中文数字+顿号短行（「壹、罪與己」）、1–4 位纯数字独行；标记后须跟行尾/空白/标点防正文误命中，标题 50 字帽；卷/部/集不当章。目录连排（≥3 行连续命中标记）整段并入正文不当章边界——连排判定不容忍空行间隔，否则目录后紧邻的正文首章会被吞进目录块（「前进」实测教训）；超短章（正文 <30 字，多为页眉/重复标题残渣）并入上一章，首章保留；书首无归属行并入第一章；预览清单含各章字数以暴露漏切，支持行内改标题与并章（首章并入下一章，其余并入上一章）。TXT 编码探测（UTF-8 严格解码失败回退 GBK）后统一转 UTF-8 入库。

## 门面协议

- `category_list` 响应行新增 `category_type`（`"1"` 音乐 / `"2"` 书籍），App 分类列表页按类型分叉点击跳转。
- 新增 `cat_books`（分页）：行结构对齐 `album_list`（`book_id / book_name / book_author / book_cover / book_cover_thumb`，缩略图对与分类图同模式）。
- 新增 `book_chapters`：全书章节目录一次性返回（`chapter_id / chapter_title`）。
- 新增 `book_chapter`：单章正文（`content`）；正文按章请求，不整本下发。
- 照旧 `ONLINE_MP3` 包裹、数值一律字符串。

## App 端跟随

- 底部导航「音乐分类」更名「分类」；分类列表页书籍分类点击进入书籍列表页（封面网格卡，形态对齐专辑卡片），点击书籍直进阅读页。
- 书单页与阅读页不显示迷你播放器（阅读场景与音乐控件互不干扰）；阅读页为常规路由：单章一屏、常驻顶栏（返回/书名/目录），章首「上一章」、章尾「下一章」；上下滚动按段渲染，顶栏「Aa」唤起阅读设置浮层（全局一份偏好）：字号五档（20–36，默认 20）+ 背景主题（护眼绿/米黄/淡青/素白/夜间，默认护眼绿）；顶栏「目录」按钮唤起底部浮层选章，当前章高亮。
- 阅读进度（章节 + 章内滚动比例——比例制保证字号调整或重排后仍落回相对位置）仅存本机（SharedPreferences），章切换/滚动节流/退出三处写入，重进续读。
- 书籍 v1 无收藏、评分、离线缓存。

## Considered Options

- 独立书籍分类表/独立内容域：分类列表页要拆区块、后台双套管理页，与「书籍分类混排进分类列表页」的产品诉求相悖，被否。
- 章节正文存 OSS 文件（逐章或整本）：与媒体体系一致但录入管理成本高、文本走 CDN 要处理 Referer 白名单、App 侧多一套文件下载与切分，被否。
- 整本 TXT 由 App 下载后自行切分：切分规则散落客户端、章节一致性无从保证，被否。
- 阅读进度带设备 ID 上服务端：多设备冲突策略与同步接口均为纯增量，本地续读已覆盖主场景，v1 被否（留作后续增量）。
- 全屏覆盖层阅读页：复刻播放器手势与层级的成本高，而边读边听本就是音乐 App 的自然场景，被否。
- 仿真/覆盖翻页与章间无缝拼接续读：分页排版引擎与跨章进度归属成本数倍于滚动形态，单章一屏已覆盖主场景，v1 被否。

## Consequences

- 「分类」语义从音乐内容分组泛化为内容分组；分类管理页需加类型维度，新建时选类型。
- 正文按章下发使 App 书籍加载为两段式（目录 + 当前章）。
- 维度顺序扩展为第三维度，后台书籍排序抽屉复用既有拖拽 + 按名称排序组件。
- 智能分章节是启发式，误切靠预览确认兜底，入库后可逐章编辑修正。

## 修订记录

- 2026-09-06 切分规则 v2（预览最小编辑同步）：原规则对馆藏 7 本真实书籍核查，6 本塌成单章（实际标记为「第一次谈话/第二封信」「函一」「1、」「001→」「壹、」「第X篇」等样式）、灵花切出 40 个空章（目录行被当章边界，且数字集缺「廿」）。扩充为四族标记 + 目录连排检测 + 超短章并入上一章；预览清单支持行内改标题与并章。录入哲学不变：启发式切分 + 预览强确认 + 单事务删旧写新，过切与漏切由预览人工兜底。
- 2026-09-06 章节顺序调整（推翻「章节不设排序字段、展示序即 id 序、不支持章节重排」）：切分序号错乱与录入中途漏章需要重排能力，Chapter 加 `chapterSort`：口径 sort ASC + id ASC 兜底——叙事序不等于维度顺序的 id DESC「新书在前」，新增章节追加书末而非插最前；存量不回填靠 id 兜底，TXT 导入按切分序赋 0..N-1。管理面板章节管理页「调整顺序」抽屉复用 DimensionDrawer（拖拽/整块移动/按名称自然升降序/显式保存），API 对齐 PUT order 全量 ids 范式且服务端强制完整校验（ids 恰为该书全部章节，部分提交整单拒，宽松现状不复刻）。`book_chapters` 门面排序跟随，响应形态不变——App 按返回序展示零改动，阅读进度按 chapterId 存本机不受重排影响，定性为非协议变更、不触发门面策略评审。
- 2026-09-06 封面缩略图尺寸分化：书单页 2 列封面大卡在 3x 屏显示宽约 540px，全局 300px 缩略图被放大 2 倍余致封面文字不可辨（音乐域展示位小无此问题）。saveImage 增 thumbSize 参数，书籍封面缩略图 720×720 inside（withoutEnlargement 小图不放大），音乐域维持 300；门面 URL 同名同源模式不变，App 零改动，非协议变更；存量 300px 缩略图由一次性脚本 rethumb:books 从 images/books/ 原图按同管线再生成覆盖。
- 2026-09-07 封面目录归一：推翻「封面走 images/books/ 专属目录」，封面上传与读取回归 images/ 与 images/thumbs/（720 缩略图分化不变）。动机：OSS 管理页按前缀列举，books/ 子目录对象与音乐图混列成噪，专属目录未换来隔离收益；DB 零改动（cover 只存文件名），存量对象搬移由运维自理。同步 OSS 管理页「原图直显」：缩略图目录仅浏览不可直传（派生物不设上传入口）、images 视图按 key 段数过滤子目录对象、列表按修改时间倒序、网格/表格/放大预览一律原图（缩略图生成保留，App 协议 mp3_thumbnail_s 等在用）；rethumb:books 脚本随目录归一作废删除。
